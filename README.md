# Qa Skillscape Hub

Crie um site de portfólio moderno, profissional e fácil de manter para mim, uma pessoa profissional de QA (Quality Assurance). O objetivo é apresentar minha experiência e meus trabalhos de forma clara e atrativa para recrutadores, facilitando a navegação e o contato.

### Objetivos do site
- Apresentar meu perfil profissional e minha área de atuação em QA.
- Exibir projetos, certificados, habilidades técnicas e currículo.
- Permitir que recrutadores encontrem rapidamente as informações mais importantes.
- Ter uma identidade visual moderna, amigável e profissional, sem parecer excessivamente informal.

### Estrutura sugerida
Inclua, no mínimo, as seguintes seções:

1. **Início / Apresentação**
   - Uma chamada de destaque com espaço para meu nome, cargo ou área de atuação e uma breve apresentação.
   - Botões para visualizar meus projetos, baixar meu currículo e entrar em contato.

2. **Sobre mim**
   - Espaço para uma apresentação profissional, objetivos e principais pontos da minha trajetória.
   - Use textos provisórios claramente identificados como conteúdo editável, sem inventar informações pessoais.

3. **Habilidades técnicas**
   - Apresente minhas skills de QA de forma visual e interativa, com uma abordagem gamificada, mas ainda profissional.
   - Considere elementos como níveis, categorias, badges ou cards interativos.
   - Não atribua níveis de proficiência sem dados fornecidos: use valores demonstrativos editáveis ou deixe-os claramente como placeholders.

4. **Projetos**
   - Crie cards para projetos com título, descrição, tecnologias ou ferramentas utilizadas, principais atividades e links opcionais para repositório ou demonstração.
   - Use conteúdo fictício apenas se estiver claramente marcado como exemplo editável.

5. **Certificados**
   - Área para listar certificados, instituição, data e, quando aplicável, link ou imagem do certificado.

6. **Currículo**
   - Inclua um botão visível para baixar o currículo em PDF.
   - Deixe o caminho do arquivo fácil de configurar e indique claramente onde adicionar ou substituir o documento.

7. **Contato**
   - Inclua opções configuráveis para e-mail e redes profissionais, como LinkedIn e GitHub.
   - Não invente dados de contato.

### Requisitos de design e experiência
- Design responsivo, com boa aparência em celular, tablet e desktop.
- Navegação intuitiva, consistente e fácil de usar.
- Visual limpo, moderno e acessível, com boa hierarquia tipográfica, contraste adequado e estados claros para botões e links.
- Microinterações e animações sutis, evitando efeitos que prejudiquem a leitura ou a performance.
- Gamificação das habilidades integrada ao visual do portfólio, sem comprometer a credibilidade profissional.
- Considere boas práticas de acessibilidade, incluindo navegação por teclado e textos alternativos quando necessário.

### Requisitos técnicos e de manutenção
- Utilize a stack padrão mais adequada à plataforma em que o prompt for executado.
- Organize o projeto em componentes reutilizáveis e mantenha o código legível e simples de atualizar.
- Centralize os dados de projetos, certificados, habilidades e contatos em uma estrutura fácil de editar, evitando espalhar conteúdo pelo código.
- Não crie funcionalidades que dependam de serviços externos ou credenciais sem explicar essa dependência.
- Inclua dados demonstrativos apenas quando necessários e identifique-os claramente para que eu possa substituí-los.

Entregue uma primeira versão funcional e visualmente consistente do site. Ao final, indique de forma breve onde devo editar meus dados e onde colocar meu currículo, meus projetos e meus certificados.
